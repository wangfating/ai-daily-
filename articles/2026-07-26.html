ECC：跨 AI Agent Harness 的"操作系统"级优化框架

📌 项目是什么

ECC 是一个面向 AI 编程 Agent 的统一操作框架（Agent Harness Operating System）。它的核心定位是解决一个日益普遍的问题：开发者在 Claude Code、Cursor、Codex、OpenCode、Gemini、Zed、GitHub Copilot 等多个 AI 编程工具之间切换时，每个工具的技能配置（Skills）、工作流（Workflows）、记忆（Memory）和安全策略都是割裂的——你需要为每个工具单独维护一套配置，重复劳动且难以保持一致性。ECC 把这些能力抽象成一个可复用的底层系统，让你的"技能"、"直觉"（Instincts）和"记忆"可以在不同 harness 之间无缝迁移。

这个项目不是简单的配置文件集合，而是一个经过 10+ 个月高强度日常工程实践打磨出来的完整系统。它内置了持续学习（Continuous Learning）、安全扫描（Security Scanning）、记忆优化（Memory Optimization）和研究优先开发（Research-First Development）等机制，涵盖了从生产级 Agent 工作流到 MCP（Model Context Protocol）配置管理的方方面面。作者 affaan-m 将其称为"harness-native operator system"，强调它是真正从实际多 harness 工程工作流中生长出来的，而不是纸上谈兵的实验品。

ECC 采用 MIT 协议开源，代码仓库已有 23 万+ Star 和 3.5 万+ Fork，背后有 230+ 位贡献者参与，支持 12 种以上编程语言生态。ECC v2.0.0 进一步引入了"Hermes Operator"故事——一个更完整的跨 harness 统一操作层，并配套了官网（ecc.tools）、Discord 社区和 GitHub App 等多种接入方式。

🎯 适用场景

  1. 多工具并行开发的工程师：如果你同时用 Claude Code 写代码、用 Cursor 做快速编辑、偶尔切到 Codex 跑批量任务，ECC 可以让你只用一套 Skills 和规则覆盖所有工具，避免在每把"锤子"上重复配置。

  2. 需要统一 AI 编码规范的团队：团队可以通过 ECC 集中管理安全扫描策略、代码风格规则和 MCP 连接配置，确保每个成员无论用什么工具，Agent 的行为边界是一致的。

  3. 长期运营 AI Agent 的团队/个人：ECC 的记忆优化和持续学习机制适合那些需要让 AI Agent 在数周甚至数月的项目中积累上下文、保持状态一致性的场景，而不是每次对话都从零开始。

  4. 研究 AI Agent 工作流的开发者：如果你在做 Agent 架构的研究，ECC 提供了一个跨 harness 的实验平台，可以比较不同 harness 下同一套 Skills 的表现差异。

  5. 追求"研究优先"开发模式的团队：ECC 内建的 research-first development 工作流适合那些需要 AI Agent 先检索文档、再生成代码、最后进行安全审查的严谨开发流程。

✨ 核心特性

  • 跨 Harness 兼容：一套配置适配 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等 7+ 个 AI 编程工具，无需为每个工具单独维护。

  • Skills 技能系统：可复用的技能模块，类似"插件"，可以在不同 harness 间共享和组合，覆盖从代码生成到调试的各类任务。

  • Instincts 直觉机制：自动化的行为模式，让 Agent 在特定场景下自动采取最优策略，减少人工干预。

  • Memory 记忆优化：对 Agent 的上下文记忆进行智能管理和压缩，避免长对话中的信息衰减和上下文溢出问题。

  • Security Scanning 安全扫描：内置安全审查能力，在 Agent 生成代码或执行命令前进行风险检测。

  • MCP 配置管理：统一管理 Model Context Protocol 的连接配置，简化 Agent 与外部工具/数据源的对接。

  • 持续学习回路：Agent 的工作结果会反馈到系统中，驱动 Skills 和 Instincts 的迭代优化，越用越"聪明"。

  • Research-First 工作流：强制 Agent 先检索和阅读相关文档/代码，再进行生成或修改，提升输出的准确性和可靠性。

🚀 快速上手

ECC 提供多种安装方式，以下是最主流的两种：

方式一：通过 npm 安装（推荐）

# 安装通用核心包
npm install -g ecc-universal

# 安装 Agent 安全护盾包
npm install -g ecc-agentshield

安装完成后，在你的项目根目录运行初始化命令，ECC 会自动检测你当前使用的 AI harness 并生成对应的配置文件。

方式二：通过 GitHub App 安装（适合团队/私有仓库）

前往 ECC GitHub App 页面 点击"Install"，授权后即可在私有仓库中使用 ECC Pro 功能（GitHub App 官方免费，私有仓库 Pro 版从 $19/seat/月起）。

接入后配置

ECC 会在你的项目中生成 .ecc/ 目录，包含：

.ecc/
├── skills/        # 技能模块目录
├── instincts/     # 直觉规则目录
├── memory/        # 记忆存储目录
└── config.yaml    # 跨 harness 统一配置

详细的使用指南和 Hermes Operator 的 v2.0.0 搭建流程，请参考项目内置的 Guides 和 v2.0.0 发布说明。
