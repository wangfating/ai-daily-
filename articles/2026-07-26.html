auto_reg：让 AI 平台账号注册自动化——Any Auto Register 深度测评

📌 项目是什么

在 AI 浪潮席卷全球的今天，ChatGPT、Cursor、Kiro、Grok 等 AI 平台已成为开发者和研究者的必备工具。然而，这些平台普遍存在注册门槛高、验证码复杂、邮箱验证繁琐等问题——尤其是当你有多个账号需求时（比如多环境测试、多用户管理、A/B 测试等），手动重复注册不仅耗时耗力，还容易因为操作过于频繁而被平台封禁 IP 或账号。

auto_reg（Any Auto Register） 正是为此而生。它是一个多平台账户自动注册与管理系统，覆盖了从 ChatGPT、Trae.ai、Cursor 到 Kiro、Grok 等多个热门 AI 平台。项目的核心价值在于：用自动化思维替代手工操作——内置浏览器引擎（Playwright + Camoufox）模拟真实用户行为，集成临时邮箱服务和验证码自动识别，配合 Web 管理界面，让"一键注册"从幻想变成现实。

项目基于 lxf746 的 any-auto-register 进行了三代迭代更新，技术栈升级为 FastAPI + React，架构更清晰，扩展性更强。

🎯 适用场景

  • AI 平台批量测试：开发者需要同时测试多个 ChatGPT / Cursor 账号的功能差异，auto_reg 可以快速批量生成账号，省去重复劳动。
  • 研究与学习：安全研究人员或学生想了解不同 AI 平台的注册流程、风控机制，通过本项目可在合规范围内进行技术学习。
  • 多账号环境管理：团队协作中需要为不同成员或项目准备独立账号，auto_reg 的批量注册和 Token 管理功能可以统一维护。
  • 临时需求快速获取：只需要一个短期使用的 AI 账号，不想绑定真实邮箱，auto_reg 内置的临时邮箱方案可以快速搞定。
  • 自动化工作流集成：通过 API 接口和定时任务功能，将账号注册融入 CI/CD 或其他自动化脚本中。

✨ 核心特性

  • 🎯 多平台全覆盖：支持 ChatGPT、Trae.ai、Cursor、Kiro、Grok、Tavily、OpenBlockLabs 等主流 AI 平台，且功能完整度各不相同（部分平台支持 Token 管理和状态同步）。
  • 🔌 插件化架构：采用标准化接口设计，新增平台只需编写插件即可接入，无需改动核心代码。
  • 📧 丰富的邮箱方案：内置 LuckMail、MoeMail、TempMail.lol、SkyMail、DuckMail 等 10+ 种临时/自托管邮箱服务，适配不同平台的注册要求。
  • 🤖 双引擎验证码处理：集成 YesCaptcha（第三方打码平台）和本地 Turnstile Solver，兼顾成功率和隐私性。
  • 🌐 代理池管理：内置代理支持，配合随机延迟机制，有效降低被平台风控拦截的概率。
  • 📊 Web 管理界面：基于 React + Ant Design 构建的可视化面板，无需命令行即可完成所有操作。
  • 🔄 定时任务支持：支持周期性自动注册，配合批量上传功能，单次最多可处理 1000 个账号。
  • 🚀 一键部署：提供 deploy.sh 脚本和 Docker Compose 方案，从零到可用环境，10 分钟内即可跑起来。

🚀 快速上手

环境要求

组件 最低版本 说明
Python 3.12+ 推荐使用 Conda 管理环境
Node.js 18+ 用于前端构建
Git 任意 克隆仓库
Docker 可选 一键部署方案

方法一：一键部署（推荐）

# 1. 克隆仓库
git clone https://github.com/dsclca12/auto_reg.git
cd auto_reg

# 2. 赋予部署脚本执行权限（Linux/Mac）
chmod +x deploy.sh

# 3. 运行一键部署脚本
./deploy.sh

部署完成后，浏览器访问 http://localhost:8000 即可看到管理界面。

方法二：手动安装

# 1. 克隆仓库并进入项目目录
git clone https://github.com/dsclca12/auto_reg.git
cd auto_reg

# 2. 创建 Python 虚拟环境（推荐使用 Conda）
conda create -n any-auto-register python=3.12 -y
conda activate any-auto-register

# 3. 安装 Python 依赖
pip install -r requirements.txt

# 4. 安装浏览器驱动（Playwright 控制的 Chromium）
python -m playwright install chromium

# 5. 下载 Camoufox（反检测浏览器指纹工具）
python -m camoufox fetch

# 6. 安装前端依赖并构建
cd frontend
npm install
npm run build
cd ..

# 7. 复制环境变量配置文件并编辑
cp .env.example .env
# 在 .env 中填入你的邮箱 API Key、代理等配置

# 8. 启动服务
python main.py

启动成功后同样访问 http://localhost:8000。

基本使用流程

  1. 配置邮箱服务：在 .env 中填写邮箱服务的 API Key（如 MoeMail、SkyMail 等），不同平台对邮箱要求不同，参考 README 中的邮箱方案表选择合适的策略。
  2. 配置验证码服务：如果你选择使用 YesCaptcha，在 .env 中填入 YESCAPTCHA_CLIENT_KEY；如果使用本地 Turnstile Solver，设置 LOCAL_SOLVER_URL。
  3. 配置代理（可选）：设置 PROXY_URL 以提高注册成功率。
  4. 在 Web 界面中选择目标平台，填写注册参数，点击开始。
  5. 查看注册结果：在管理界面中查看每个账号的注册状态、Token 信息等。

💡 使用建议

✅ 什么时候推荐使用

  • 你有明确的批量注册需求（如团队多账号管理、AI 平台压力测试）。
  • 你需要技术学习和研究自动化注册流程、风控对抗等话题。
  • 你愿意投入时间配置邮箱和验证码服务，因为这些是注册成功的关键变量。

⚠️ 什么时候不适合使用

  • 你只是偶尔注册一两个账号——手动注册可能更简单直接。
  • 你希望100% 注册成功——任何自动化工具都无法绕过平台的风控策略，Kiro 等平台对邮箱要求极其严格。
  • 你打算用于商业批量注册或恶意用途——项目明确声明仅供学习研究，且可能违反平台使用条款。

👥 适合人群

  • 自动化爱好者：对浏览器自动化（Playwright）、反检测技术（Camoufox）感兴趣的动手玩家。
