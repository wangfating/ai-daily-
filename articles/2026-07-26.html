📌 项目是什么

ECC 是一个面向 AI Agent 的"操作系统级"优化框架，它的目标是把散落在各个 AI 编码工具（Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等）中的工作流统一管理起来。它不仅仅是一套配置文件，而是一个完整的系统，涵盖了技能（Skills）、本能决策（Instincts）、记忆优化、持续学习、安全扫描、规则与 MCP 配置等多个维度。换句话说，ECC 试图把一个 AI 编码助手从"能用"提升到"好用、懂你、安全可控"的水平。

该项目由开发者 affaan-m 维护，已经历了 10+ 个月的高强度日常使用打磨，来源于真实的跨 Harness 工程实践。它以 MIT 协议开源，核心功能免费使用，同时提供付费的 ECC Pro GitHub App（用于私有仓库），由社区赞助者和付费用户共同支撑项目的持续迭代。截至 README 发布时，项目已积累超过 21 万 Stars 和 32,000+ Forks，拥有 230+ 位贡献者，支持 12 种以上的编程语言生态。

🎯 适用场景

  • 多工具链开发团队：团队中有人用 Claude Code、有人用 Cursor、有人用 Codex，ECC 提供统一的 Skills 和 Rules 配置，让协作口径一致。
  • 需要长期记忆的 AI 工作流：ECC 的 Memory 系统能记住项目上下文和过往决策，避免每次对话都从零开始，适合长期维护的项目。
  • 安全敏感的生产环境：内置安全扫描（Security Scanning）和规则引擎，可以在 Agent 执行前对代码变更进行校验，降低风险。
  • 追求效率的独立开发者：通过预置的 Skills 和 Instincts，让 AI 助手快速理解你的编码习惯和项目规范，减少手动 prompting 的成本。
  • MCP（Model Context Protocol）重度用户：ECC 提供 MCP 配置的管理和自动发现能力，方便接入各种外部工具和服务。

✨ 核心特性

  • 跨 Harness 兼容：一套配置适配 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等多个主流 AI 编码工具，无需为每个工具重复配置。
  • Skills 技能体系：可复用的 AI 操作技能库，覆盖常见开发场景，开箱即用或自定义扩展。
  • Instincts 直觉机制：基于项目上下文自动推断最佳操作路径，减少手动干预。
  • Memory 记忆优化：持续学习并记忆项目历史、决策模式和用户偏好，让每次对话都更有延续性。
  • Security Scanning 安全扫描：在 Agent 执行前后自动进行安全检查，拦截潜在的代码风险。
  • MCP 配置管理：统一管理 Model Context Protocol 的连接和配置，简化工具集成。
  • Hooks 与 Rules：可自定义的钩子和规则系统，精细控制 Agent 的行为边界。
  • Hermes Operator 故事（v2.0.0 新增）：ECC v2 引入了公共 Hermes 操作叙事层，提供更清晰的跨 Harness 架构指引。

🚀 快速上手

1. 通过 npm 安装（推荐）

ECC 提供两个核心 npm 包：

# 安装通用包（适用于大多数场景）
npm install ecc-universal

# 安装 AgentShield（安全增强层）
npm install ecc-agentshield

2. 通过 GitHub App 安装（适合团队/私有仓库）

前往 ECC Tools GitHub App 页面 安装到你的组织或个人仓库，即可解锁 ECC Pro 的高级功能。

3. 验证安装

安装完成后，可以通过以下命令验证 ECC 是否正常工作：

# 查看 ECC 版本
ecc --version

# 查看可用技能列表
ecc skills list

# 初始化项目配置
ecc init

4. 配置你的第一个 Skill

在项目根目录创建 .ecc/ 目录，添加自定义规则和技能配置：

mkdir -p .ecc
# 从 ecc-universal 模板复制默认配置
cp node_modules/ecc-universal/templates/.ecc/* .ecc/

⚠️ 安全提示

请仅从官方渠道安装 ECC：GitHub 仓库（github.com/affaan-m/ECC）、npm 包（ecc-universal、ecc-agentshield）、GitHub App（ecc-tools）、插件 slug ecc@ecc 以及官网 ecc.tools。第三方重新上传的镜像不受项目维护，可能包含恶意代码。

💡 总结与展望

ECC 是当前 AI Agent 工具链中少有的"基础设施级"项目——它不满足于做一个 prompt 模板或单工具插件，而是试图建立一套跨工具、跨项目的统一操作标准。对于已经在多个 AI 编码工具之间切换、或者希望 AI 工作流更规范、更安全的开发者来说，ECC 值得一试。随着 v2.0 的 Hermes 架构逐步完善，以及 230+ 贡献者的持续投入，这个项目有望成为 AI Agent 生态中的"默认配置层"。
