ECC：跨 Agent Harness 的性能优化操作系统

📌 项目是什么

ECC 是一个面向 AI Agent 工作流的性能优化系统（agent harness performance optimization system）。它不是一个简单的配置文件集合，而是一个完整的操作系统层，为 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等多个 AI Agent harness 提供统一的能力底座——涵盖技能（Skills）、启发式规则（Instincts）、记忆优化（Memory Optimization）、安全扫描（Security Scanning）、持续学习（Continuous Learning） 以及研究优先的开发范式（Research-First Development）。

项目的核心理念是：开发者不需要为每个 AI Agent 工具单独维护一套工作流配置。ECC 将通用的 Agent 操作能力抽象为可复用的模块，让一套技能、规则和记忆体系能在多个 harness 之间无缝切换。经过 10+ 个月的密集日常使用打磨，它已经从一个个人工具演变为支持 12+ 语言生态、拥有 230+ 贡献者的跨平台开源项目。

ECC 采用 MIT 协议开源，核心功能完全免费；同时提供 ECC Pro 版 GitHub App（私有仓库从 $19/座位/月起），由社区赞助者和订阅用户共同支持项目的持续迭代。

🎯 适用场景

  1. 多 Agent 工具并行使用的开发者：同时使用 Claude Code、Codex、Cursor 等多个 AI 编程助手的工程师，可以通过 ECC 统一管理技能、规则和配置，避免在每个工具中重复设置。

  2. 需要安全合规的 AI 工作流团队：ECC 内置安全扫描和规则引擎，适合需要在 AI 生成的代码进入生产环境之前进行安全检查和策略校验的团队。

  3. 长期维护复杂项目的工程团队：ECC 的记忆优化和持续学习机制能帮助 Agent 在长时间、多轮次的开发任务中保持上下文一致性，减少"遗忘"问题。

  4. 希望提升 AI Agent 工作效率的个人开发者：通过 Skills（预置技能包）和 Instincts（启发式规则），让 Agent 在日常编码、调试、文档生成等任务中表现得更"懂行"。

  5. 需要 MCP（Model Context Protocol）统一配置的场景：ECC 提供了 MCP 配置和 Legacy Command Shims 的管理能力，适合需要对接多种外部工具链的复杂开发环境。

✨ 核心特性

  • 跨 Harness 统一工作流：一套配置同时适配 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等多个 Agent 平台，无需为每个工具单独维护。
  • Skills 技能系统：预置和自定义可复用的 Agent 技能包，覆盖编码、调试、文档生成等多种开发场景，开箱即用。
  • Instincts 启发式规则：内置基于真实工程经验提炼的"直觉"规则，让 Agent 在做决策时更贴近人类工程师的判断逻辑。
  • Memory Optimization 记忆优化：自动管理 Agent 的上下文记忆，在长周期任务中保持关键信息不丢失，提升多轮交互的连贯性。
  • Security Scanning 安全扫描：在 Agent 输出进入代码仓库之前进行安全检查，拦截潜在的漏洞和风险代码。
  • MCP 配置管理：集中管理 Model Context Protocol 的连接配置，简化 Agent 与外部工具/数据源的对接流程。
  • Continuous Learning 持续学习：系统会根据使用反馈不断优化自身的行为策略，越用越"聪明"。
  • Hermes Operator Story（v2.0.0 新增）：v2.0.0 引入了公共的 Hermes 操作者（Operator）故事层，在可复用能力之上提供更高层次的自动化工作流编排。

🚀 快速上手

ECC 提供多种安装方式，可根据你的使用场景选择：

方式一：通过 npm 安装（推荐）

ECC 提供两个 npm 包，分别对应不同的功能维度：

# 安装通用核心包
npm install ecc-universal

# 安装 Agent Shield 安全相关包
npm install ecc-agentshield

方式二：通过 GitHub App 安装

前往 ECC Tools GitHub App 点击安装，免费版支持公开仓库，私有仓库可订阅 ECC Pro。

方式三：通过插件系统

在支持的 Agent harness 中使用插件标识 ecc@ecc 进行加载。
