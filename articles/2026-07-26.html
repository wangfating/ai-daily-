📌 项目是什么

ECC（Agent Harness Controller）是一个面向 AI 编码助手的" Agent 编排操作系统"，旨在为 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等多种 AI Agent 运行环境（Harness）提供一套统一的性能优化与工作流管理能力。它的核心定位是：把 AI Agent 从"零散的配置集合"升级为具备技能（Skills）、本能（Instincts）、记忆（Memory）、安全扫描和持续学习能力的生产级工作系统。

项目由作者 affaan-m 经过 10+ 个月的高强度日常开发打磨而来，积累了超过 23 万 Star 和 3.5 万 Fork，汇聚了 230+ 位贡献者。它覆盖了 12+ 种编程语言生态，支持跨 Harness 的 Agent 工作流编排——无论你用哪个 AI 编程助手，ECC 都试图提供一套"一次配置、多处生效"的标准化能力层。

🎯 适用场景

  • 团队统一 AI 编码规范：在 Claude Code、Cursor 等多个 Harness 中共享同一套 Skills、Rules 和 MCP 配置，保证团队 AI 辅助编码风格一致。
  • 安全敏感的 AI 工作流：通过内置的 ecc-agentshield 安全扫描模块，在 Agent 执行命令或访问外部资源前进行安全校验，适合企业级内部工具链。
  • 跨工具迁移：如果你团队里有人用 Claude Code、有人用 Codex、有人用 Cursor，ECC 提供统一的配置层，降低多工具并行带来的学习和管理成本。
  • 生产环境 Agent 管理：利用 Memory 优化和持续学习机制，让 AI Agent 在长期项目中逐步"记住"项目的架构和约定，减少重复提问。
  • MCP 配置集中管理：一键部署和管理多个 MCP（Model Context Protocol）服务器的连接配置，无需在每个 Harness 中重复设置。

✨ 核心特性

  • 跨 Harness 兼容：一套配置同时适配 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等主流 AI 编码助手。
  • Skills & Instincts 系统：可复用的 Agent 技能库和"本能"规则，让 AI 在特定场景下自动触发正确的行为模式，无需每次都手动提示。
  • Memory 优化：自动管理 Agent 的上下文记忆，避免长对话中的信息丢失和"遗忘"问题。
  • ecc-agentshield 安全层：独立的安全扫描工具，在 Agent 执行命令、读取文件或调用外部服务前进行风险评估。
  • MCP 配置管理：集中式管理 Model Context Protocol 的连接和配置，支持多服务器统一维护。
  • Hooks & Rules：通过 Hook 机制在 Agent 工作流的各个节点注入自定义逻辑（如代码风格检查、提交前验证等）。
  • Hermes Operator 故事（v2.0.0 新增）：v2.0.0 引入了公开的 Hermes Operator 架构，提供更高级的跨 Harness 工作流编排能力。
  • MIT 开源 + GitHub App：核心开源免费，Private 仓库可通过 GitHub App（ecc-tools）按席位订阅使用。

🚀 快速上手

1. 通过 npm 安装

# 安装核心通用包
npm install -g ecc-universal

# 安装安全扫描模块（可选但推荐）
npm install -g ecc-agentshield

2. 通过 GitHub App 安装（免费）

前往 ECC Tools GitHub App 页面，点击"Install"按钮将其安装到你的 GitHub 组织和仓库中。

3. 通过项目官网获取完整指南

访问 ecc.tools 获取各平台的详细安装文档和配置模板。

4. 配置示例（以 Claude Code 为例）

安装完成后，在项目根目录创建 ECC 配置文件：

# .ecc/config.yml
skills:
  - code-review
  - test-generation
  - commit-message

rules:
  - no-secrets-in-commits
  - type-check-before-push

memory:
  enabled: true
  max_entries: 500

mcp_servers:
  - name: github
    command: npx
    args: ["@github/mcp-server"]

5. 启动并验证

# 验证 ECC 已正确加载
ecc status

# 运行安全扫描
ecc-agentshield scan

更多详细配置请参考项目中的 Hermes Setup Guide 和 v2.0.0 发布说明。

💡 总结与展望

ECC 是目前生态中最系统化的 AI Agent 工作流编排框架之一——它不只是零散的配置文件，而是一套融合了技能管理、安全控制和持续学习的完整系统。对于同时使用多种 AI 编码助手（尤其是 Claude Code + Cursor + Codex）的个人开发者和工程团队来说，ECC 提供了一个值得认真考虑的"中间层"解决方案。
