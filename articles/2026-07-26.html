📌 项目是什么

ECC（The Agent Harness Operating System） 是一个面向 AI 编程代理（AI Agent）的跨平台性能优化系统。它的核心定位是：把分散在各 AI 编码工具中的配置、能力与工作流统一起来，形成一套可复用、可迁移的"代理操作系统"。简单说，如果你同时用 Claude Code、Cursor、Codex、OpenCode 等多个 AI 编程助手，ECC 能帮你一套配置走遍所有工具，避免在每个工具里重复折腾。

项目由作者 affaan-m 发起，经过 10+ 个月的高强度日常工程实践打磨，积累了 23 万+ Star 和 35000+ Fork，背后有 230+ 位贡献者。它不是简单的配置文件集合，而是涵盖了技能（Skills）、直觉规则（Instincts）、记忆优化、安全扫描、持续学习等完整能力的生产级系统。同时，项目提供 MIT 完全开源版本（ECC OSS），并配套 ECC Pro 付费版（GitHub App），为私有仓库提供托管服务。

🎯 适用场景

  1. 多工具 AI 编程用户：同时使用 Claude Code、Cursor、Codex 等多个 AI 助手，希望一套配置无缝切换，减少重复劳动。
  2. 团队协作与标准化：团队需要统一的 AI 编码规范、安全策略和 MCP（Model Context Protocol）配置，ECC 提供了可分发的规则和技能包。
  3. 生产环境 AI Agent 部署：需要为 AI Agent 注入安全扫描、记忆优化和持续学习能力的工程场景，ECC 提供了生产级别的 hook 和规则体系。
  4. MCP 工作流管理：使用 MCP（Model Context Protocol）连接外部工具和数据源时，ECC 的 MCP 配置管理能力可以简化接入流程。
  5. 长期 AI 辅助开发项目：项目周期长、需求迭代频繁，ECC 的"持续学习"和"记忆优化"机制能帮助 AI 代理在长期协作中保持上下文一致性。

✨ 核心特性

  • 跨 Harness 兼容：一套配置同时适配 Claude Code、Cursor、Codex、OpenCode、Gemini、Zed、GitHub Copilot 等 7+ 个 AI 编程工具。
  • Skills 技能体系：可复用的 AI 代理技能包，覆盖常见开发场景，即插即用。
  • Instincts 直觉规则：基于真实工程经验提炼的自动化行为规则，让 AI 代理"越用越聪明"。
  • Memory 记忆优化：对 AI 代理的上下文记忆进行智能管理，避免长对话中的信息丢失和上下文膨胀。
  • Security Scanning 安全扫描：内置安全检查能力，在 AI 生成代码或执行操作时自动检测风险。
  • MCP 配置管理：统一管理 Model Context Protocol 的连接与配置，简化外部工具接入。
  • Hooks 钩子机制：支持在工作流各节点注入自定义逻辑，实现高度可定制的自动化流程。
  • 12+ 语言生态支持：涵盖 JavaScript/TypeScript、Python、Go、Java、Perl、Shell、Markdown 等多语言开发场景。

💡 ECC v2.0.0 新增了 Hermes Operator 公共故事层（Public Hermes Operator Story），在可复用层之上提供更完整的操作范式，详见 Hermes Setup Guide 和 2.0.0 发布说明。

🚀 快速上手

ECC 提供多种安装方式，OSS 版本完全免费：

1. 通过 npm 安装（推荐）

# 安装通用包
npm install ecc-universal

# 安装 AgentShield 安全组件
npm install ecc-agentshield

2. 通过 GitHub App 安装（免费）

前往 ECC Tools GitHub App 一键安装到你的仓库，支持私有仓库的 Pro 版本（从 $19/座位/月 起）。

3. 从源码部署

git clone https://github.com/affaan-m/ECC.git
cd ECC
# 按照项目内的配置指引进行设置

安装后配置：

安装完成后，ECC 会自动为你的 AI 编程工具注入优化配置。你可以在项目根目录查看生成的配置文件，根据需要调整 Skills、Instincts 和 MCP 设置。详细配置指南请参考项目官网 ecc.tools 和文档目录 docs/ 下的各 harness 适配指南。

⚠️ 安全提醒：请仅从上述官方渠道安装 ECC。第三方重新上传的镜像未经项目维护，可能包含恶意代码。
