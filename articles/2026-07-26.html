ECC：AI Agent 的"操作系统"级优化框架

📌 项目是什么

ECC 的全称是 Engineer Coding Companion，它是一个面向 AI 编程 Agent 的"操作系统级"性能优化系统。在 Claude Code、Cursor、Codex、OpenCode 等 AI 编程工具日益普及的今天，开发者面临的核心痛点是：每个 Harness（AI 运行环境）都有自己独立的配置、技能和记忆体系，导致工作流碎片化、经验无法复用。ECC 试图解决这个问题——它不是一个简单的配置文件集合，而是一个完整的 Agent 工作流系统，内置了 Skills（技能）、Instincts（直觉机制）、Memory Optimization（记忆优化）、持续学习、安全扫描和研究驱动开发等功能。它让开发者构建一次"标准化 Agent 能力"，就能在多个 AI 编程工具间无缝复用。

该项目由作者 affaan-m 维护，基于 10+ 个月的高强度日常工程实践打磨而成，已支持 12+ 语言生态和多个主流 AI Agent 平台。核心定位是：在 AI 编程这个新兴领域，建立一套类似操作系统的统一调度和资源管理层。

🎯 适用场景

  1. 跨平台 AI coding 工作流：团队同时使用 Claude Code 和 Cursor 开发时，需要统一的代码规范和最佳实践自动应用，ECC 提供一套 Skills 库覆盖所有 Harness。
  2. 企业级 AI Agent 安全管理：在多个 AI Agent 中强制执行安全扫描、权限控制和敏感信息过滤，ECC 内置 Security Scanning 模块可集中管理。
  3. 长期项目的知识沉淀：让 AI Agent 记住项目的历史决策、架构约束和踩过的坑，避免每次对话都"失忆"，ECC 的 Memory Optimization 专门解决此问题。
  4. MCP（Model Context Protocol）集成优化：为 Agent 配置和管理 MCP 工具，减少上下文浪费，提升 token 利用效率。
  5. 从传统命令行向 AI Agent 迁移：提供 legacy command shims（遗留命令桥接），平滑过渡现有开发工作流，降低团队 adoption 成本。

✨ 核心特性

  1. 跨 Harness 兼容（Cross-Harness）：支持 Claude Code、Codex、Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等主流 AI 编程工具，一次配置多端生效。
  2. Skills 系统：可复用的技能库，封装常见工程模式（如代码审查、调试、架构设计）和最佳实践，直接注入 Agent 工作流。
  3. Instincts（直觉机制）：基于历史交互数据自动优化 Agent 的行为决策，让 Agent 逐渐"学会"团队的编码习惯。
  4. Memory Optimization：智能管理上下文记忆，避免 token 浪费和"上下文遗忘"，在长周期项目中保持 Agent 的连贯性。
  5. Security Scanning：内置安全扫描层，在代码产出阶段检测漏洞和敏感信息泄露，实现"安全左移"。
  6. Hermes Operator（v2.0 新增）：引入公共操作层，提供标准化的 Agent 编排能力和可复用的基础设施层。
  7. GitHub App 集成：ECC Pro 提供云端托管的 GitHub App，支持私有仓库的高级功能（如自动扫描、策略执行）。
  8. 多语言生态支持：不仅限于 JavaScript，还覆盖 TypeScript、Python、Go、Java、Perl、Markdown 等 12+ 语言环境。

🚀 快速上手

ECC 提供多种安装方式，可根据团队环境选择：

方式一：npm 包安装（推荐）

# 安装核心通用包
npm install ecc-universal

# 或安装安全扫描专用包
npm install ecc-agentshield

方式二：GitHub App（适合团队/企业）

  1. 访问 ECC GitHub App 页面
  2. 安装到你的组织或仓库
  3. 配合 ECC Pro 订阅使用私有仓库高级功能（从 $19/seat/mo 起）

方式三：插件方式

在支持的 Harness 中搜索插件 slug ecc@ecc 即可启用。

验证安装

安装完成后，可通过以下命令验证：

# 查看 ecc-universal 版本
npx ecc-universal --version

⚠️ 重要安全提示：请仅从以下官方渠道安装，第三方镜像未经审核可能存在恶意软件风险：

  • GitHub 仓库：github.com/affaan-m/ECC
  • npm 包：ecc-universal 和 ecc-agentshield
  • GitHub App：github.com/apps/ecc-tools
  • 插件 slug：ecc@ecc
  • 官方网站：ecc.tools
