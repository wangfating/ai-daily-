prompts.chat：全球最大的开源 AI 提示词库，一行命令私有化部署

作者：f | GitHub Stars：166k+ | 主要语言：TypeScript / Next.js | 官网：prompts.chat

📌 项目是什么

你有没有过这样的经历？打开 ChatGPT，面对一个空白的输入框，大脑却一片空白——"我到底该问它什么？" 或者试了好几种说法，结果质量天差地别。提示词（Prompt）的质量，直接决定了 AI 输出结果的上限，这是目前 AI 使用者面临的最大痛点之一。

prompts.chat 就是为了解决这个问题而生的。它是目前全球最大的开源 AI 提示词库，聚合了来自社区的数万条高质量提示词，覆盖写作、编程、分析、角色扮演等多种场景。项目最初以 Awesome ChatGPT Prompts 之名在 2022 年 12 月发布，如今已更名并扩展为一个完整的提示词生态系统——不仅是一个"列表"，更提供了交互式学习手册、儿童提示词游戏、CLI 工具、MCP 服务器，以及最重要的——一键私有化部署能力，让组织可以在完全保留数据隐私的前提下使用这份prompt资源库。

它的核心价值在于：把"如何与 AI 对话"这件事，从玄学变成工程。无论是个人用户想提升效率，还是企业想搭建内部 AI 工作流，prompts.chat 都提供了一个开箱即用的基础设施。

🎯 适用场景

  • AI 写作助手搭建：内容创作者、运营人员可以快速找到"写文章""改写文案""生成摘要"等场景化提示词，直接复制使用，省去反复调试的时间。
  • 企业内部 AI 私有化部署：团队希望使用 ChatGPT、Claude、Gemini 等模型，但又不希望数据外泄——通过 self-host 部署私有提示词库，搭配自选模型接口，实现完全可控的 AI 工作流。
  • Prompt Engineering 学习：学生、开发者想系统学习"如何写好提示词"，可以通过项目内置的 25+ 章节交互式书籍（涵盖链式推理、Few-shot 学习、Agent 设计等进阶技巧）循序渐进。
  • 教孩子与 AI 交互：内置的 "Promi" 儿童游戏通过趣味谜题和故事，教 8-14 岁的孩子理解如何向 AI 提问，培养下一代 AI 素养。
  • 快速原型验证：开发者用 CLI 工具或 MCP Server 在本地开发环境中直接调用提示词库，快速测试不同 prompt 的效果。

✨ 核心特性

  1. 海量社区驱动的提示词库：数万条经过社区验证的 prompt，涵盖写作、编程、分析、翻译、营销等数十个类别，持续更新。
  2. 一键私有化部署（Self-Host）：通过 npx prompts.chat new 命令即可在本地或服务器上部署完整的提示词库，支持自定义品牌、主题、认证方式（GitHub/Google/Azure AD）和 PostgreSQL 数据库。
  3. 多模型兼容：不仅支持 ChatGPT，还兼容 Claude、Gemini、Llama、Mistral 等主流开源和闭源模型。
  4. 交互式提示词工程手册：25+ 章的免费在线书籍，从基础到进阶（链式推理 Chain-of-Thought、Few-shot、Agent 构建），适合零基础入门。
  5. MCP Server 支持：以 Model Context Protocol 服务形式接入你的 AI 工具（如 Claude Code），让提示词库成为 AI 的"外部知识插件"。
  6. CLI 工具：通过 npx prompts.chat 命令行直接调用，方便集成到自动化脚本和工作流中。
  7. 儿童友好模式（Promi）：游戏化设计，让孩子在玩乐中学会如何与 AI 有效沟通。
  8. 开源且可贡献：项目完全开源，任何人都可以通过 prompts.chat/prompts/new 提交新的提示词，自动同步到主仓库。

🚀 快速上手

方式一：一键创建（推荐）

# 1. 使用 npx 直接创建一个全新的提示词库项目
npx prompts.chat new my-prompt-library

# 2. 进入项目目录
cd my-prompt-library

# 3. 运行设置向导（配置品牌、主题、认证方式等）
npm run setup

设置向导会引导你完成以下配置：

  • Branding：自定义项目名称、Logo、颜色主题
  • Authentication：选择认证方式（GitHub OAuth / Google OAuth / Azure AD / 无认证）
  • Database：连接 PostgreSQL 数据库（推荐使用 Neon 的托管服务）
  • Features：开关 MCP Server、CLI 等功能模块

方式二：从源码部署

# 1. 克隆仓库
git clone https://github.com/f/prompts.chat.git
cd prompts.chat

# 2. 安装依赖
npm install

# 3. 运行初始化设置
npm run setup

使用 MCP Server（接入 Claude Code 等工具）

在你的 AI 工具配置中添加以下 JSON：

{
  "mcpServers": {
    "prompts.chat": {
      "url": "https://prompts.chat/api/mcp"
    }
  }
}

如果需要本地部署：

{
  "mcpServers": {
    "prompts.chat": {
      "command": "npx",
      "args": ["-y", "prompts.chat", "mcp"]
    }
  }
}

使用 CLI 命令

# 直接调用 prompts.chat CLI
npx prompts.chat

# 或者安装后全局使用
npm install -g prompts.chat
prompts.chat

💡 使用建议

✅ 什么时候用

  • 团队需要统一 AI 使用标准：通过 self-host 部署，为团队提供经过筛选的高质量提示词模板，保证输出质量的一致性。
  • 数据敏感场景：金融、医疗、法律等行业的组织需要将 AI 数据保留在内部网络，私有化部署是唯一选择。
  • 想系统学习 Prompt Engineering：交互式书籍从零开始讲解，配合实际 prompt 示例，比纯文字教程高效得多。
  • 需要快速集成到现有 AI 工作流：MCP Server 和 CLI 工具让你可以轻松把提示词库嵌入到开发流程中。

❌ 什么时候不用

  • 只是偶尔用一下 AI：个人轻度用户直接访问 prompts.chat 浏览即可，没必要本地部署。
  • 只需要单一模型且追求最简单方案：如果只用 ChatGPT 且不在意隐私，原始 Awesome ChatGPT Prompts 仓库更轻量。
  • 预算极其有限且不想折腾服务器：Self-host 需要 PostgreSQL 数据库和一定的运维成本，不适合零基础设施的场景。
  • 需要付费 prompt 市场：如果你想买卖 prompt（而不是免费使用社区资源），PromptBase 这类平台更合适。
