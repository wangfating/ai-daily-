📌 这篇文章说了什么

这篇文章详细记录了如何使用腾讯出品的 AI 桌面助手 WorkBuddy，结合 HeyGen 开源的 HyperFrames 框架，从零开始制作一条 30 秒的“AI 发展三阶段”科普短视频。整个过程全程对话式操作，完全不需要打开剪映等传统剪辑软件。文章的亮点在于不仅给出了从环境搭建到生成 MP4 的完整流程，还分享了如何通过多轮对话追加动画、配音和字幕的实战经验，并附带了许多针对国内网络环境和 Mac 系统的避坑指南。

HyperFrames 的核心思路是“写 HTML，出视频”，WorkBuddy 负责将自然语言转化为符合视频渲染规范的 HTML 代码，再由 HyperFrames 渲染成 MP4。这种方式把视频制作从“剪辑时间轴”变成了“写前端页面”，极大降低了非专业视频创作者的入门门槛。

🎯 核心观点

  1. HTML 即视频，颠覆传统剪辑逻辑：HyperFrames 的核心逻辑是“写 HTML，出视频”，将视频制作转化为前端开发，彻底绕开了时间轴、关键帧等传统剪辑概念，让懂代码或会描述需求的人都能做视频。
  2. 对话式迭代，告别重复造轮子：WorkBuddy 支持多轮对话追加修改（如加动画、改字幕年份），无需像 Codex 或 Claude Code 那样每次重新跑全量 Prompt，实现了“说一句改一处”的高效工作流。
  3. 国内可用性需做关键适配：默认的 Kokoro TTS 模型国内下载易超时，必须指定微软免费的 edge-tts 替代，才能保证语音生成的稳定性，这是国内用户必须注意的“坑”。
  4. 适用场景有明确边界：该方案非常适合数据可视化、概念解说等以文字图表为主的“纯解说”视频，但不适合需要真人出镜或复杂视觉特效的场景。

💡 深度解读

工具链解析：谁在做什么？

整个流水线由三个核心组件构成，分工明确：

  • WorkBuddy：腾讯出品的 AI 桌面助手（支持 Windows/Mac），相当于一个懂代码的副驾驶。它负责接收你的自然语言指令，将需求拆解，并生成/修改代码文件。
  • HyperFrames：HeyGen 开源的视频渲染框架，负责把 HTML+CSS+JS 渲染成 MP4 视频文件。没有它，WorkBuddy 只能写出普通网页代码，无法生成视频。
  • FFmpeg：最经典的开源视频编码工具，HyperFrames 在渲染最终 MP4 时必须调用它。

传统剪辑 vs. HTML 转视频

维度 传统剪辑（如剪映） HyperFrames + WorkBuddy
操作方式 拖拽时间轴，调整关键帧动画 对话式描述，用 HTML/CSS 控制元素
上手门槛 需学习软件界面、排版与转场 需了解基础 HTML 结构或会描述逻辑
迭代成本 拖动轨道，导出预览查看效果 追加自然语言指令，实时预览刷新
适合内容 真人出镜、复杂转场、表情包 数据图表、概念可视化、文字动画

关键技术细节：TTS (文本转语音) 与字幕对齐

文章特别强调了 TTS 的选型。HyperFrames 默认使用 Kokoro 模型，但其模型文件托管在海外，国内网络下载极易超时。因此，作者在 Prompt 中直接指定使用 edge-tts（微软的免费语音 API），无需下载模型，国内网络稳定且中文语音质量足够。

字幕的精确对齐也颇具巧思：edge-tts 会返回每个字的时间戳，WorkBuddy 会自动把这些时间戳映射到 HTML 的 data-start 和 data-duration 属性上，从而实现字幕与语音的毫秒级同步。

代码示例：安装 HyperFrames Skills

要让 WorkBuddy 写出能渲染视频的 HTML，必须安装 HyperFrames Skills（扩展包）。打开终端，在项目目录下运行：

# 安装 HyperFrames Skills，确保 WorkBuddy 了解视频渲染的 HTML 规范
# --full-depth 参数表示拉取完整的依赖和示例代码
npx skills add heygen-com/hyperframes --full-depth

安装完成后，在 WorkBuddy 中输入 /hyperframes，如果看到路由器菜单列出创作工作流，说明环境配置成功。

🚀 如何实践

按照以下步骤，你可以在 10 分钟内跑通第一条 AI 视频：

  1. 环境准备：确保已安装 Node.js 22+、FFmpeg（macOS 用户用 brew install ffmpeg，Windows 用户去官网下载或执行 winget install ffmpeg），并下载安装 WorkBuddy。
  2. 添加技能：在项目目录下执行上述 npx skills add heygen-com/hyperframes --full-depth 命令。
  3. 启动创作：打开 WorkBuddy，切到项目目录，输入 /hyperframes，选择 /faceless-explainer（纯概念解说工作流）。
  4. 生成初版：输入 Prompt，例如：“用 /faceless-explainer 做一个 30 秒的科普短视频，16:9 横屏，深色背景。内容为 AI 发展的三个阶段：规则系统、机器学习、大模型时代。”
  5. 对话式迭代：在 Craft 模式下追加修改意见，例如“给阶段标题加滑入带回弹的动画”、“使用 edge-tts 生成中文旁白”、“代表事件加上具体年份”。
  6. 最终渲染：Windows 用户可在 WorkBuddy 内直接渲染；Mac 用户需在 WorkBuddy 内预览修改，但最终渲染 MP4 需另开终端执行 npx hyperframes render。
